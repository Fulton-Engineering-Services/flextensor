    Simplified API¶

    Module-level convenience functions — the recommended way to use FlexTensor. These wrap the OffloadManager singleton for common use cases.

    DEFAULT_MANAGER_NAME module-attribute ¶

    DEFAULT_MANAGER_NAME: str = 'default'

    Name used by :func:get_offload_manager when no explicit name is provided.

    init ¶

    init(config: OffloadConfig | None = None, name: str = DEFAULT_MANAGER_NAME)

    offload ¶

    offload(model: Module, config: OffloadConfig | None = None, name: str = DEFAULT_MANAGER_NAME) -> Module

    Offload modules using the specified offload manager.

    PARAMETER DESCRIPTION
    model

    PyTorch model to patch.

    TYPE: Module

    config

    OffloadConfig to use for offload (patterns from config.module_patterns).

    TYPE: OffloadConfig | None DEFAULT: None

    name

    Name for the offload manager. Defaults to DEFAULT_MANAGER_NAME.

    TYPE: str DEFAULT: DEFAULT_MANAGER_NAME

    RETURNS DESCRIPTION
    Module

    The patched model.

    get_offload_manager ¶

    get_offload_manager(name: str = DEFAULT_MANAGER_NAME) -> OffloadManager

    Get or create an OffloadManager singleton.

    PARAMETER DESCRIPTION
    name

    Name for the offload manager. Defaults to DEFAULT_MANAGER_NAME.

    TYPE: str DEFAULT: DEFAULT_MANAGER_NAME

    RETURNS DESCRIPTION
    OffloadManager

    OffloadManager instance
    RAISES DESCRIPTION
    RuntimeError

    If the named manager was created by a different thread.

    Examples:

    >>> om = get_offload_manager()
>>> om.set_config(OffloadConfig(gpu_device=0))

    get_gpu_memory_usage ¶

    get_gpu_memory_usage(name: str = DEFAULT_MANAGER_NAME) -> GPUMemoryUsage

    Get GPU memory usage by the specified offload manager.

    Returns the memory used by GPU transfer blocks and unmapped tensors. Must be called after the manager has transitioned to inference mode.

    PARAMETER DESCRIPTION
    name

    Name for the offload manager. Defaults to DEFAULT_MANAGER_NAME.

    TYPE: str DEFAULT: DEFAULT_MANAGER_NAME

    RETURNS DESCRIPTION
    GPUMemoryUsage

    GPUMemoryUsage dataclass with memory breakdown in bytes and megabytes.
    RAISES DESCRIPTION
    RuntimeError

    If called before inference mode.

    Lazy Model Initialization¶

    load_model_from_profile ¶

    load_model_from_profile(tensor_manager: TensorManager, profile_directory: str, model_class: type[Module], model_args: tuple = (), safetensor_path: str | None = None, model_kwargs: dict | None = None, buffer_device: str | None = None, diagnose: bool = False, strict: bool = False) -> Module

    Load a model from a saved profile state with optimized weight loading.

    This function creates a model with parameters on meta device and buffers on GPU, then loads only the necessary weights from safetensors based on the profile state. This is more memory-efficient than loading the full model.

    PARAMETER DESCRIPTION
    tensor_manager

    The TensorManager instance to use for state restoration

    TYPE: TensorManager

    profile_directory

    Directory containing the profile (profile.json)

    TYPE: str

    model_class

    The model class to instantiate (e.g., Transformer)

    TYPE: type[Module]

    model_args

    Positional arguments for the model constructor

    TYPE: tuple DEFAULT: ()

    safetensor_path

    Path to the safetensors file. Required.

    TYPE: str | None DEFAULT: None

    model_kwargs

    Keyword arguments for the model constructor

    TYPE: dict | None DEFAULT: None

    buffer_device

    Device for model buffers (default: uses tensor manager's device)

    TYPE: str | None DEFAULT: None

    diagnose

    If True, run diagnostics on nested parameter tracking

    TYPE: bool DEFAULT: False

    strict

    If True, raise KeyError when any tensor key from the profile is missing in the safetensors file. Default False.

    TYPE: bool DEFAULT: False

    RETURNS DESCRIPTION
    Module

    The loaded model in eval mode, ready for use with tensor_manager
    RAISES DESCRIPTION
    KeyError

    If strict=True and any profile tensor keys are missing from safetensors
    Example

    from flextensor import TensorManager from flextensor.lazy_model_init import load_model_from_profile

    tensor_manager = TensorManager(device_gpu, ...) model = load_model_from_profile( ... tensor_manager, ... "./profile", ... Transformer, ... model_args=(model_args,), ... safetensor_path="/path/to/model.safetensors", ... ) tensor_manager.set_model(model) model.set_tensor_manager(tensor_manager) model = tensor_manager.initialize_warmup()
